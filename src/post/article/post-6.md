### ディレクトリの問題点

通常，起動構成を作成するとその起動構成ごとに _screenshots_ ディレクトリが作成されてしまう．  
そのためすべてのスクリーンショットをまとめて閲覧する事が出来ない．この問題を解決するためにシンボリックリンクを使用することを考えた．

### シンボリックリンクとは

シンボリックリンクとは、自身は実体を持たないが任意のファイルやフォルダであるかのように扱うことのできる中継地点のようなもの．

### 作成方法

以下にシンボリックリンクを作成するためのコマンドを提示する．

```bash
mklink /j シンボリックリンクを作成する場所のパス*1 アクセスしたい場所のパス*2
```

例) 各起動構成のスクリーンショットフォルダをひとつにまとめたい場合

```bash
mklink /j \User\AppData\Roaming\Minecraft\screenshots \User\Pictures\Screenshots
```

### 応用

今回はスクリーンショットディレクトリでの活用を紹介したが、_resource pack_ や _shader pack_ のディレクトリにも活用することができる。
